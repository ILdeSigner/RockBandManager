⚙️ Uruchamianie w Chmurze i Lokalne CLI

W Twoim repozytorium znajduje się już gotowy harmonogram GitHub Actions oraz modułowy skrypt Python.

PowerShell / Bash
# 1. Scraping klubów do CSV:
python rock_booking_engine.py --mode scrape

# 2. Generowanie ogłoszenia rekrutacyjnego:
python rock_booking_engine.py --mode recruit

# 3. Wysyłka e-mail z zebranymi kontaktami:
python rock_booking_engine.py --mode email

# 4. Pełen cykl (Scrape + Recruit + Email):
python rock_booking_engine.py --mode all

1. Darmowe 2000 minut/mies. na GitHub Actions.
2. Plik konfiguracyjny to .github/workflows/weekly_booking.yml.
3. Wykonuje się automatycznie w każdy poniedziałek o 09:00 UTC.
4. Aby dodać klucze i e-mail, wejdź w:
Repozytorium -> Settings -> Secrets and variables -> Actions i dodaj:

  • SMTP_USER (Twój Gmail)
  • SMTP_PASSWORD (Hasło do aplikacji Google)
  • RECIPIENT_EMAIL (Twój mail odbiorcy)
  • SERPAPI_KEY (Opcjonalny klucz)
